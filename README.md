# 月相羅針 計算PoC v0.11｜出生地入力例「兵庫県神戸市」版

春華プロジェクトの「月相羅針 Web計算サービス」を技術検証するための、小規模な Flask + Vue 3 Web アプリです。

v0.11では、**v0.10の機能・画面構成・Flask API・Python計算をそのまま維持し、出生地入力欄の表示例だけを「例：兵庫県小野市」から「例：兵庫県神戸市」へ変更**しました。計算用の基準テストデータ（兵庫県小野市）は回帰確認のため変更していません。

```text
ブラウザ
  ↓
Vue 3（入力・共通日時ピッカー・画面制御・結果表示）
  ↓ fetch / JSON
Flask API
  ↓
既存Python計算
  ├─ astronomy.py
  ├─ phase_classifier.py
  └─ location_master.py
```

## 重要

この PoC は、**月相羅針の正式占術仕様を確定するものではありません。**

現在の P01〜P08 は、360°を45°ずつ8等分し、標準的な月相名称とPoC用説明文章を割り当てた技術確認用の仮仕様です。春華独自の正式な月相羅針の ID・名称・角度範囲・境界条件・説明文・特徴・進み方が確定したら、`phase_classifier.py` の定義を差し替える前提です。

出生時間不明時の `stable` / `ambiguous` 候補判定も、**PoCの技術検証仕様であり、春華独自の正式な出生時間不明時ルールではありません。**

## v0.11 の変更点

- 出生地入力欄のプレースホルダーを `例：兵庫県小野市` から `例：兵庫県神戸市` へ変更
- v0.10の共通日時ピッカー、Flask API、Python計算、P01〜P08、exact / stable / ambiguous は変更なし

### v0.10から維持している共通日時入力UI

- 生年月日・出生時間から `input type="date"` / `input type="time"` を廃止
- Vue 3で開閉・一時選択値・決定・キャンセルを管理する共通モーダルUIを追加
- 生年月日は「年｜月｜日」、出生時間は「時｜分」で選択
- 年は直接入力、±1年、±10年、マウスホイールで移動可能
- 月・日・時・分はWeb標準のスクロール領域＋CSS scroll snapで選択
- 月・日・時・分はタップ／クリック、ホイール／トラックパッド、上下矢印キーで操作可能
- 生年月日の年は西暦1〜9999年を入力でき、UI都合で狭い年範囲を設けていません
- うるう年と月ごとの日数をVue側でも確認し、存在しない日付を決定不可
- 空欄から開いた場合は端末ローカルの現在年月日／現在時刻を**選択UI内部の初期値**に使用
- 選択UIを開いただけでは `form` 値を変更せず、「決定」時のみ反映
- 「キャンセル」または背景クリック、Escapeキーでは元の値を維持
- 出生時間は「出生時間を未入力に戻す」で空欄へ戻せる
- APIへ送る形式は従来どおり `YYYY-MM-DD` / `HH:MM`
- 生年月日・出生時間の表示は入力欄中央を維持
- 出生地入力、結果画面、P01〜P08、45°区分、exact / stable / ambiguous は維持

## Vue 3 の導入方式

PoCを軽量に保つため、Vue 3はCDN版をHTMLから読み込みます。

```html
<script src="https://cdn.jsdelivr.net/npm/vue@3/dist/vue.global.prod.js"></script>
```

Node.js、Vue CLI、Vite、TypeScript、Pinia、別フロントエンド開発サーバーは不要です。従来どおり `python app.py` だけでFlaskを起動できます。

## 入力UI仕様

### 生年月日

- 入力欄をクリック／タップすると共通選択UIを開きます。
- 空欄なら端末ローカルの現在年月日を選択UI内部の初期値にします。
- 既存値があればその値を初期値にします。
- 年は4桁までの直接入力と ±1 / ±10 操作が可能です。
- 年の有効範囲は Python `datetime` と整合する西暦1〜9999年です。
- 月・日は縦スクロールまたはタップ／クリックで選択できます。
- うるう年を判定し、月・年変更で現在の日が存在しなくなった場合は有効な最終日へ調整します。
- 「決定」で `YYYY-MM-DD` として確定します。
- 「キャンセル」、背景クリック、Escapeでは変更しません。

### 出生時間

- 出生時間は任意です。
- 空欄なら端末ローカルの現在時刻を選択UI内部の初期値にします。
- 既存値があればその値を初期値にします。
- 24時間表記で、時は00〜23、分は00〜59を1分単位で選択できます。
- 「決定」で `HH:MM` として確定します。
- 「キャンセル」、背景クリック、Escapeでは変更しません。
- 「出生時間を未入力に戻す」で空欄へ戻せます。

出生時間が空欄のまま計算された場合は、12:00等の仮時刻を設定せず、出生日全体を対象に候補判定します。

### リセット

フォームのresetイベントでは、前回計算値へ戻さず次をクリアします。

- 生年月日
- 出生時間
- 出生地
- 結果
- エラー

## 計算API

### `POST /api/calculate`

リクエスト例：

```json
{
  "birth_date": "1964-09-03",
  "birth_time": "11:23",
  "birth_place": "兵庫県小野市"
}
```

出生時間が分からない場合：

```json
{
  "birth_date": "1964-09-03",
  "birth_time": "",
  "birth_place": "兵庫県小野市"
}
```
